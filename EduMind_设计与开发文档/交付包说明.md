## 当前项目快照

- 前端技术栈：Vue 3、Vite、TypeScript、Vue Router、Pinia、Three.js、ECharts、GSAP、@vueuse/motion。
- 后端技术栈：Node.js 原生 HTTP 服务、结构化 JSON 数据、SQLite/WASM 本地协作数据、LLM Provider 抽象层。
- 核心智能体：ProfileAgent、ResourceAgent、PathAgent、TutorAgent、EvaluationAgent、ReflectionAgent、KnowledgePathAgent，以及 Orchestrator。
- 首页展示口径：6 个业务模块、12 个可视化协作角色节点，展示从画像采集到反馈回写的闭环。
- 当前主路由：`/login`、`/home`、`/admin`、`/dialogue`、`/profile`、`/learning-path`、`/evaluation`、`/reverse-evaluation`、`/tutoring`、`/settings`、`/edu-mind`、`/resources`、`/trainflow`。
- 当前核心接口：`/api/health`、`/api/llm/status`、`/api/profile/analyze`、`/api/profile/save`、`/api/resources/generate`、`/api/agents/run`、`/api/evidence/traces`、`/api/evidence/summary`、`/api/knowledge-path/generate`、`/api/agent-collaboration`。

## 推荐验收命令

```bash
npm run build
npm run test:navigation
npm run test:chat-api
```

说明：`npm run build` 会执行 Tailwind 生成、`vue-tsc --noEmit` 和 Vite 生产构建，是当前前端健康检查的主命令。构建产物 `dist/` 可随时重新生成，不需要纳入最终交付版本。
